# Bottom Up Impact — standalone website

Open this folder in VS Code. The site uses only HTML5, CSS3 and vanilla JavaScript, with no framework, package install or build step.

## Run
Open `index.html` in a browser, or use VS Code's Live Server extension and choose **Open with Live Server**. Follow the project links to open each project. Fonts use Google Fonts when internet access is available; a system font fallback is included. All photographs, the uploaded logo and favicon are included locally.

## Source
- Nine HTML pages at the folder root.
- `css/style.css`: shared styling and navy/turquoise colors sampled from the supplied logo (#212159 and #24ADC8).
- `js/main.js`: shared logo, header/footer, menus, filters, diagrams and form validation.
- `js/projects-data.js`: project descriptions and project selection.
- `assets/`: local photographs, official supplied logo and favicon.

## Before accepting messages or publishing final content
Message delivery is not connected: validation works, but no message is sent or saved, and the site tells the visitor this. Replace the marked integration point with your real form service before launch.
Official Vision/Mission statements, contact details, social URLs, articles, partner details and fuller project descriptions remain clearly marked placeholders. The photographs are illustrative generated images, not verified photographs of these actual projects.

The delivered folder contains no React, TypeScript, Tailwind, or framework files.
